# Community Code of Conduct

Common Knowledge Field is about making shared understanding less costly while preserving difference, agency, and consent. The project community should embody the same commitments.

## Expected conduct

- Engage ideas and evidence without attacking people.
- Make room for uncertainty, correction, minority perspectives, and changed minds.
- Respect names, pronouns, boundaries, privacy, and consent.
- Give actionable review feedback and receive good-faith correction without retaliation.
- Avoid publishing personal, relational, or security-sensitive information.

Harassment, discrimination, threats, sexualised attention without consent, deliberate misgendering, doxxing, coercion, and sustained disruption are not acceptable.

## Reporting and enforcement

Report security or data-exposure concerns through the private route in `SECURITY.md`. For other conduct concerns, privately contact a repository maintainer through their GitHub profile rather than opening a public issue containing personal details.

Maintainers may edit or remove contributions, restrict participation, or ban accounts when necessary to protect participants and the project. Enforcement decisions should minimise disclosure and record only what is necessary.
