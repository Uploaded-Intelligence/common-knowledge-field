# Risks and mitigations

| Risk | Severity | Mitigation and stop rule |
|---|---:|---|
| False consensus or jointness | Critical | Joint ratification is structurally impossible without every participant's affirmative judgment; false-agreement rate must remain below 5%. |
| Raw-content leakage | Critical | Separate stores, encrypted relay envelopes, release grants, plaintext relay inspection; any leak blocks M5. |
| Coercive sharing | High | Private-first default, preview, explicit copy action, no automatic invitation, honest revocation limits. |
| AI authority effect | High | Provisional visual language, evidence access, uncertainty, optional sparse corrections, no truth language. |
| Visual churn increases load | High | Incremental identity/layout and stability metrics; M1 blocks below 95% unaffected identity/position preservation. |
| Salience becomes interruptive | High | Maximum three items, no OS notifications, confidence threshold, user correction feedback, M4 energetic-viability gate. |
| Prompt injection in messages | High | Treat content as data, constrained structured output, no model tools, schema and evidence validator. |
| Beeper API drift | High | Owned adapter, `/v1/info` capability discovery, contract fixtures, polling fallback, no send endpoints. |
| Local model too slow/heavy | High | Fixed M2 bake-off; smallest passing model; simplify ontology before considering larger models. |
| Deletion semantics mislead | High | Tombstone deleted source evidence and disclose that downloaded shared material cannot be remotely erased. |
| Dependency/licence contamination | Medium | SPDX inventory, exact pins, notices, no EchoMind/tldraw code, review adapted upstream code. |
| Premature group expansion | High | V2 work is blocked until the dyadic M4 gate passes. |
| Public contribution leaks relational data | Critical | The public repository contains source and synthetic fixtures only. Contribution guidance prohibits real transcripts, participant identifiers, screenshots, credentials, and private exports; security-sensitive findings use private reporting. Any leak triggers immediate containment and history-remediation review. |
| Public GitHub governance is underconfigured | Medium | Require pull requests, CI, CODEOWNERS review, private vulnerability reporting, and security scanning where GitHub permits them; keep local review gates as defence in depth. |
