# Roadmap

1. **M0 Control plane:** purpose, governance, research, risk, threat model, CI, private GitHub-ready repository.
2. **M1 Replayable field:** synthetic event stream, canonical schema, stable map, lenses, evidence, corrections, outline accessibility.
3. **M2 Semantic bake-off:** T3C-derived, direct structured-output, LangExtract, and Graphiti competitors; select by fixed evidence/latency/memory gates.
4. **M3 Live private field:** Beeper adapter, encrypted ledger, local model runner, docked macOS app, reconciliation and recovery.
5. **M4 Private pilot:** nine sessions across three consenting dyads; pass energetic-viability gate.
6. **M5 Shared field:** release bundle, PWA, encrypted Automerge relay, mutual judgments, revocation semantics.
7. **M6 Hardening:** accessibility, security, recovery, packaging, review, completion packet.
8. **V2:** group salience, plural clustering, map-to-map transfer, self-hostable relay, supported native adapters.

No later milestone begins before its predecessor's gate passes. M5 is explicitly blocked on M4 usefulness.
