# Common Knowledge Field

Common Knowledge Field (CKF) is a local-first companion that turns an unfolding text conversation into a living, plural, evidence-bound relational map.

The system updates automatically while people text. It distinguishes expression, interpretation, agreement, commitment, uncertainty, change, and productive difference without asking humans to manually summarise the conversation.

This is an early-stage public, community-contributable project. The canonical purpose and acceptance contract is in [`docs/WINNING.md`](docs/WINNING.md). The repository is public; conversation data and pilot deployments remain private by design.

## Current status

M0 control-plane bootstrap is verified. M1 is in progress: a replayable, renderer-neutral living-field core exists on the `codex/m1-living-field` development branch, while the contributor-ready React Flow application remains to be built and verified. Beeper ingestion, local inference, and shared fields follow only after the relevant gates pass.

## Contributing

Contributions are welcome. Start with [`CONTRIBUTING.md`](CONTRIBUTING.md), the milestone sequence in [`docs/ROADMAP.md`](docs/ROADMAP.md), and an issue marked `good first issue` or `help wanted`.

Never submit real private-message transcripts, credentials, participant identifiers, or screenshots containing conversation content. Use synthetic or explicitly consented fixtures only.

Security-sensitive findings should follow [`SECURITY.md`](SECURITY.md), not a public issue.
